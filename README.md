# famoalimentos.mx

Sitio de Famo Alimentos: portada (landing) y catálogo de **Quesos Sn Roque**, **Villa Magna** y **Don Fito**, con pedido por WhatsApp.

- `index.html`: inicio
- `quesos-san-roque/`, `villa-magna/`, `don-fito/`: página de cada marca
- `img/`, `fonts/`, `media/`, `icons/`: fotos, letras, videos e iconos
- `robots.txt`, `sitemap.xml`: para Google

**Vista previa:** esta versión está armada para verse en `https://diegotristan101-a.github.io/FAMOALIMENTOS/` y no se indexa en Google. Cuando el dominio `famoalimentos.mx` apunte aquí, se publica la versión final (rutas en la raíz y visible para Google).
